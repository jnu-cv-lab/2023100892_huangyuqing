# 手写数字识别——传统机器学习模型对比实验

## 一、实验目的

1. 掌握传统机器学习方法在图像分类任务中的应用流程，包括数据加载、预处理、模型训练与评估。
2. 对比不同分类模型（KNN、朴素贝叶斯、逻辑回归、SVM、决策树、随机森林）在手写数字识别任务中的性能差异。
3. 学习使用混淆矩阵、错误样本分析等方法，评估模型的分类效果并分析误差来源。
4. 理解图像数据的原始像素特征表示方法及其优缺点。

## 二、实验环境与数据集

### 1. 实验环境

- 操作系统：Windows 11 + WSL Ubuntu
- 开发工具：VS Code
- 编程语言：Python 3.12
- 主要依赖库：scikit-learn、OpenCV、matplotlib、numpy

### 2. 数据集说明

本次实验使用 scikit-learn 内置的 Digits 手写数字数据集，该数据集包含：

| 属性 | 说明 |
|:---|:---|
| 样本总数 | 1797 张 8×8 灰度图像 |
| 类别 | 0~9 共 10 类手写数字 |
| 特征表示 | 每张图像展平为 64 维向量，对应 8×8 像素值 |
| 数据划分 | 按 75% 训练集、25% 测试集进行划分 |
![alt text](image.png)

## 三、实验原理与方法

### 1. 数据预处理

将 8×8 的灰度图像按行展平为 64 维向量，作为模型的输入特征，同时将数据集划分为训练集和测试集，其中训练集用于模型学习，测试集用于评估模型的泛化能力。

### 2. 分类模型介绍

本次实验对比了 6 种不同的传统机器学习分类器：

| 模型 | 基本原理 | 特点 |
|:---|:---|:---|
| K 近邻（KNN） | 基于距离度量的分类方法，通过投票选择最近邻的类别 | 无训练过程，简单直观，对数据分布无假设 |
| 朴素贝叶斯 | 基于贝叶斯定理和特征独立假设的概率模型 | 计算速度快，对小规模数据表现较好 |
| 逻辑回归 | 线性模型，通过 sigmoid 函数输出类别概率 | 可解释性强，适合线性可分数据 |
| 支持向量机（SVM） | 寻找最优超平面最大化类别间隔 | 对高维数据表现优秀，泛化能力强 |
| 决策树 | 基于特征阈值的树形结构分类模型 | 可解释性强，容易过拟合 |
| 随机森林 | 多棵决策树的集成学习方法 | 抗过拟合能力强，稳定性好 |

### 3. 模型评估指标

- **准确率（Accuracy）**：正确分类的样本数占总样本数的比例。
- **混淆矩阵（Confusion Matrix）**：展示模型在每个类别上的预测结果，可直观反映类别间的误判情况。
- **错误样本分析**：选取部分被错误分类的样本，分析误差产生的原因。

## 四、实验结果与分析

### 1. 不同模型准确率对比

本次实验中 6 种模型在测试集上的准确率如下表所示：

| 模型 | 测试准确率 |
|:---|:---|
| KNN | 0.9867 |
| Naive Bayes | 0.8311 |
| Logistic Regression | 0.9644 |
| SVM | 0.9911 |
| Decision Tree | 0.8800 |
| Random Forest | 0.9756 |

**结果分析**：SVM 模型的测试准确率最高（99.11%），其次是 KNN 和随机森林；朴素贝叶斯模型的准确率最低（83.11%）。

### 2. 混淆矩阵（以 SVM 模型为例）

为了进一步分析模型的分类效果，选取表现最优的 SVM 模型绘制混淆矩阵。
![alt text](image-1.png)

**观察结论**：
- 模型对数字 0、1、2 的识别准确率接近 100%，几乎没有误判。
- 数字 5、8、9 存在少量误判，主要集中在形状相似的类别之间（如 5 和 6、8 和 1）。

### 3. 错误分类样本分析

本次实验中，SVM 模型在测试集上共产生 6 个错误分类样本。
![alt text](image-2.png)

**误差原因**：
1. 笔画模糊、边缘不清晰的手写数字，特征区分度较低。
2. 形状高度相似的数字（如 8 和 1、5 和 6），模型难以区分。
3. 部分样本的灰度值分布不均匀，影响了模型对像素特征的判断。

### 4. 结果分析与讨论

- 基于距离度量的模型（SVM、KNN）在像素级特征的手写数字分类任务中表现最优，说明这类模型能够有效捕捉像素间的空间关系。
- 朴素贝叶斯模型表现较差，主要原因是其“特征独立”的假设不符合手写数字像素特征之间的强相关性。
- 决策树模型容易过拟合，在测试集上的表现不如集成学习方法（随机森林）。

## 五、实验总结与改进建议

### 1. 实验总结

本次实验成功完成了手写数字分类任务，对比了 6 种传统机器学习模型的性能，验证了 SVM 模型在该任务中的优势，同时通过混淆矩阵和错误样本分析，明确了模型的误差来源。

### 2. 改进建议

- **特征优化**：可以使用 HOG 等手工特征替代原始像素，提高模型对形状特征的提取能力。
- **模型调参**：对 SVM、随机森林等模型的参数进行网格搜索，进一步提升准确率。
- **数据增强**：通过旋转、平移等数据增强方法，提高模型对数字形变的鲁棒性。
- **模型融合**：使用多个模型的集成学习方法，结合不同模型的优势，降低误判率。
